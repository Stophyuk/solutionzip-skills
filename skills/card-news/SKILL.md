# 카드뉴스 스킬

디자인 툴 없이 HTML로 카드를 짜고, 헤드리스 크롬으로 카드마다 사진을 찍는다. 글꼴 · 색 · 줄바꿈이 코드로 고정돼 몇 번을 뽑아도 같은 결과가 나오고, 고칠 때는 문장만 바꾸면 된다.

## 순서

1. **기획 — 한 장에 한 메시지.** 먼저 장마다 한 줄씩 적어 사용자에게 보여 준다.
   - 1장 표지: 3초 안에 읽히는 문장 하나. 핵심 단어 하나만 강조.
   - 2~(n-1)장 본문: 번호 + 한 문장 + 받쳐 주는 한 줄.
   - 마지막 장: 할 일 하나(저장 · 보내기 · 링크).
   - 다섯 장 안팎이 기본. 열 장을 넘기지 않는다.
2. **HTML 쓰기.** 이 폴더의 `template.html`을 작업 폴더로 복사해 `deck.html`로 고친다.
   - 카드 하나 = `<section class="card r45" data-card="파일-이름">`. 판형은 `r45`(4:5 피드 1080×1350) · `r11`(1:1) · `r916`(9:16 스토리 · 릴스 표지).
   - 큰 제목은 `data-fit`을 붙이고 줄마다 `<span class="ln">`로 나눈다. 줄이 칸보다 넓으면 렌더러가 글자를 줄여 맞춘다.
   - 색과 글꼴은 맨 위 `:root` 토큰만 바꾼다. 카드마다 색을 따로 칠하지 않는다.
   - 사진은 작업 폴더 안 파일을 `<img src="./img/a.jpg">`로. 남의 이미지는 쓸 권리가 있는 것만.
3. **찍기 · 검사.** `node <이 폴더>/render.mjs deck.html out` — 카드마다 `out/<이름>.png`와 `out/report.json`.
   - **실패**(넘침 · 안전 영역 밖 · 사진 빠짐)가 하나라도 있으면 고쳐서 다시 찍는다. 실패가 남은 채로 넘기지 않는다.
   - **경고**(28px보다 작은 글자 · 한 장 90자 넘음)는 읽고 판단한다.
4. **보여 주기.** PNG를 열어 직접 본다. 줄이 이상하게 끊긴 곳, 강조가 두 군데 이상인 곳이 없는지.
5. **캡션.** 첫 줄은 표지와 같은 말로 시작하고, 해시태그는 다섯 개 이하. 링크가 필요하면 '프로필 링크' · '고정 댓글'로 안내한다.

## 지킬 것

- 확인 안 된 숫자 · 최상급 · 보장 표현을 쓰지 않는다("무조건", "100%", "최고"). 숫자는 출처가 있는 것만.
- 참여를 조건으로 걸지 않는다("팔로우하면 드려요" — 메타 스팸 정책 위반). 자료는 링크로 열어 둔다.
- AI로 만든 사실적인 이미지를 넣으면 올릴 때 매체의 AI 표시 칸을 켠다.
- 자세한 점검표는 `checklist.md`.

## 필요한 것

- Node 18 이상, 작업 폴더에서 `npm i playwright` 한 번. 설치된 크롬을 먼저 쓰고, 없으면 `npx playwright install chromium`.
- 글꼴은 Pretendard를 CDN으로 불러온다(인터넷이 필요). 오프라인이면 글꼴 파일을 받아 `@font-face`로 바꾼다.
