# 카톡 알림 스킬

긴 작업을 걸어 두고 자리를 비울 때, 끝났는지 보러 오지 않아도 되게 한다. 맥의 카카오톡 앱 창에 글을 붙여 넣고 보내는 방식이라 따로 가입하거나 키를 받을 것이 없다.

보내는 알림은 두 가지다.
- `✅ <폴더> 작업 끝 (12분)` — 한 번의 요청이 정한 시간(기본 3분)보다 오래 걸렸을 때만. 짧은 답마다 울리지 않는다.
- `⏳ <폴더> 확인이 필요해요` — 클로드가 실행 허락을 기다릴 때.

## 순서

1. **맞는 환경인지 본다.** macOS이고 카카오톡 데스크톱이 깔려 있어야 한다. 아니면 여기서 멈추고 알린다.
2. **파일 복사.** 이 폴더의 `scripts/` 세 파일을 `~/.claude/kakao-notify/`로 복사하고 `kakao_send.sh`에 실행 권한을 준다.
3. **접근성 권한.** 사용자에게 부탁한다: 시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용 → 클로드 코드를 돌리는 앱(터미널 · iTerm · 데스크톱 앱)을 켠다.
4. **보낼 창 정하기 — 가장 중요하다.** 사용자에게 카톡에서 '나와의 채팅' 창을 열어 맨 앞에 두라고 한 뒤, 창 이름을 읽는다.
   ```sh
   osascript -e 'tell application "System Events" to get name of window 1 of process "KakaoTalk"'
   ```
   나온 이름이 나와의 채팅 창이 맞는지 사용자에게 확인받고 `~/.claude/kakao-notify/config.json`에 적는다.
   ```json
   { "title": "<읽은 창 이름>", "minMinutes": 3, "wait": true }
   ```
   알림은 맨 앞 창의 이름이 이 값과 **정확히 같을 때만** 나간다. 다른 사람 채팅이 앞에 있으면 보내지 않고 넘어간다.
5. **시험 한 통.** 사용자가 지켜보는 상태에서 보낸다.
   ```sh
   KAKAO_SELF_TITLE="<창 이름>" ~/.claude/kakao-notify/kakao_send.sh "카톡 알림 시험"
   ```
   `OK`가 나오고 나와의 채팅에 글이 뜨면 성공이다. `SKIP`이면 맨 앞 창이 다르거나 카톡이 꺼져 있다.
6. **훅 등록.** `settings.hooks.json`의 세 훅을 `~/.claude/settings.json`에 합친다. 이미 있는 훅은 지우지 않고 배열에 더한다. 바꾸기 전에 바뀌는 부분을 사용자에게 보여 준다.
7. **끝 확인.** 새 세션에서 짧은 요청을 해 보고(알림이 안 와야 정상), 기다리는 시간을 바꾸고 싶으면 `minMinutes`를 고친다.

## 지킬 것

- 사용자가 창 이름을 확인하기 전에는 훅을 켜지 않는다. 잘못된 창에 붙여 넣으면 남에게 메시지가 간다.
- 시험 발송은 사용자가 보고 있을 때 한 번만 한다. 몰래 여러 번 보내지 않는다.
- 보내는 순간 카톡 창이 잠깐 앞으로 나오고 붙여 넣기를 한다. 그때 치던 글자가 섞일 수 있다고 미리 알린다.
- 클립보드는 보낸 뒤 원래 내용으로 되돌린다(글자만 되돌린다. 그림을 복사해 둔 경우는 사라질 수 있다).
- 알림 문구에 작업 내용 · 파일 이름 · 키 같은 것을 넣지 않는다. 폴더 이름과 걸린 시간만.

## 필요한 것

- macOS, 카카오톡 데스크톱(로그인 상태), Node 18 이상.
- 시험만 해 보려면 `KAKAO_NOTIFY_DRY=1`을 붙이면 보내지 않고 글만 찍는다.
- 끄려면 `~/.claude/settings.json`에서 `kakao-notify`가 들어간 훅 세 줄을 지운다.
