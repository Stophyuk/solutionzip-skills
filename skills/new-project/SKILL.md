# 새 프로젝트 시작

홈 폴더에서 시작한 일은 git도 CLAUDE.md도 없이 배포까지 가기 쉽다. 그러면 되돌릴 길이 없고, 프로젝트 규칙과 기억이 홈 세션에 섞인다. 첫 파일을 쓰기 전에 이 순서를 먼저 밟는다.

## 순서

1. 이름, 한 줄 목적, 종류(제품 / 외주 / 실험)를 확인한다. 기본 위치는 제품 `~/<이름>`, 외주 `~/clients/<이름>`. 사용자가 다른 규칙을 쓰고 있으면 그것을 따른다.
2. 폴더를 만들고 `git init`. `.gitignore`에 `.env*`(단 `!.env.example`), `node_modules/`, `.DS_Store`, 빌드 산출물.
3. `CLAUDE.md` 뼈대를 쓴다. `CLAUDE.md.example`을 바탕으로 60줄을 넘기지 않는다.
4. GitHub 원격은 만들기 전에 묻는다. 허락하면 `gh repo create <이름> --private --source . --push`.
5. 첫 커밋 뒤 "이 폴더에서 새 세션으로 이어 가자"고 말하고, 여는 명령(`cd <폴더> && claude`)을 알려 준다. 홈 세션에서 이어서 만들지 않는다.

## CLAUDE.md에 넣지 않는 것

- 진행 상황 · 날짜 · 금액. 이런 것은 금방 낡는다. 문서 · git · 세션 시작 훅이 맡는다.
- 아직 정하지 않은 규칙. "하지 말 것"은 실제로 정해진 것만.
