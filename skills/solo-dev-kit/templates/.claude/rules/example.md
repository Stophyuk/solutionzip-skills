# 시험 파일 — 이 경로의 파일을 열 때만 뜬다

본보기 규칙이다. `paths:`에 맞는 파일을 읽거나 고칠 때만 이 내용이 컨텍스트에 들어온다 — CLAUDE.md에 모든 규칙을 몰아 두면 세션마다 다 읽히고 길어진다.
프로젝트에 맞게 파일 이름 · `paths:` · 내용을 바꾸거나, 필요 없으면 지운다. 규칙 하나에 파일 하나(`server.md` · `screens.md` · `migrations.md` …).

## 정본

- 값은 정본 한 곳에만 둔다. 여기엔 그 파일을 가리키는 줄과 절차만 — 예: 시험 명령은 `package.json` scripts.

## 지킬 것

- 실패하는 시험을 지우거나 건너뛰기로 바꿔 통과시키지 않는다. 시험이 틀렸다고 보이면 그렇게 말하고 묻는다.
- 시험이 운영 데이터 · 실제 외부 서비스를 건드리지 않게 한다. 필요한 값은 픽스처로 만든다.

## 지난 실수

- (`YYYY-MM-DD 무엇 → 다음엔` — `/record`가 이 경로에서 난 실수를 여기에 한 줄씩 보탠다. 10줄을 넘기면 같은 유형을 합친다.)
